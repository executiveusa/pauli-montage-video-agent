- **Derivatives:** three ≤30-second vertical previews on origins, progress, and still-needed work. Frame individually, do not simply crop subject heads. Create a storyboard/source-shot evidence ledger.
- **Method:** read `AGENTS.md`, `AGENT_GUIDE.md`, `PROJECT_CONTEXT.md`, select the correct source-footage documentary/hybrid pipeline from actual `pipeline_defs/`, run tool preflight and dry run. Favor existing deterministic FFmpeg and Remotion rather than new AI generation. The current YAPPY-CLIPZ web UI is not assumed production-ready.
- **Gate:** source rights/identifiable participants verified; narrative meaning preserved; captions accurate; audio intelligible; no copyrighted music without a license; final export probed with ffprobe, visibly reviewed, versions logged.
- **Scope:** source-footage edit and quality tests only, no publishing, paid model calls, new accounts or fundraising claim approval without human authorization.
- **Failure handling:** record missing tools/install/cost; keep an executable FFmpeg-only fallback and report what actually rendered vs planned. Never use simulated preview screenshots as proof of a finished film.
- **Deliverable:** source manifest; timestamps and approvals; scene selection; render script or project state; validated master and 3 shorts (where feasible), plus format-by-format reports. Handoff to Agent Indigo with references, not copies of sensitive footage.
