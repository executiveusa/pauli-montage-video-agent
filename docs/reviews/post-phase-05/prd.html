Acceptance criteria

  • Registry matrix has no blank CLI/API/MCP mapping for stable public actions.
  • API-created project can be listed through CLI and inspected through MCP.
  • MCP-read timeline can be replaced through CLI and reopened through API.
  • Equivalent invalid, stale, unauthorized, and duplicate requests produce equivalent problem documents.
  • An ICM run created through one transport can be prepared, verified, handed off, and resumed through the others.
  • Another agent can resume from the handoff without original chat history.
  • Remote mode never treats a caller tenant field/header as authoritative identity.
  • No secrets or binaries appear in context packages or snapshots.
  • Existing Phase 00-05 gates remain green.
  • Exact final head passes strict OpenSpec, CI, review, and READY Vercel preview.
  • Phase 06 remains fail closed for hosted project access until Phase 07 authentication/API deployment is approved.
