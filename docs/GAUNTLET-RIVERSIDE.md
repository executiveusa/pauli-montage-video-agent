# Riverside Gauntlet — MONTAGE

Use this rubric on every production slice. The critic compares the actual output with Riverside's current product experience, not a description of it.

## Blind-judge questions
1. Can a non-technical creator understand the next action in under five seconds?
2. Does the screen lead with the user's production outcome instead of internal architecture?
3. Is every visible primary control wired to a real path?
4. Does AI remove work rather than add configuration?
5. Can the user always tell what source footage, edit version, and output they are acting on?
6. Are failure, cost, and approval states explicit?
7. Does mobile preserve the primary workflow rather than collapse into a brochure?
8. Would a skeptical editor call the copy specific, human, and useful rather than AI-generated filler?

## Automatic rejection
Reject the slice if it contains any of the following:
- fake analytics or fake success metrics;
- provider/model jargon in the default creator flow;
- placeholder buttons, disabled features presented as available, or sample-only data without labeling;
- repeated cards that merely restate feature names;
- architecture copy where a user benefit should be;
- animations with no production meaning;
- unverified 'production ready', 'live', or 'complete' claims;
- an edit action that cannot be traced back to source media and project state.

## Bar
Riverside's current product presents an end-to-end content flow — record, edit, repurpose, stream, publish — and emphasizes editing simplicity, AI-assisted cleanup/repurposing, captions, and multi-track control. MONTAGE does not need to clone Riverside's feature set; it must match that level of clarity and reduce complexity for footage-led production.
