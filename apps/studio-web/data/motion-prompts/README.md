`videos.json` is a trimmed copy of the source `data/videos.json`: slug, author, author_url, post_url, category, tech_tags, prompt, prompt_partial, added. Preview image URLs and marketing links were dropped.

Every prompt belongs to its creator. The studio UI shows the creator handle and a link to the original post next to each prompt. If a creator asks for an entry to be changed or removed, remove it from this file.
