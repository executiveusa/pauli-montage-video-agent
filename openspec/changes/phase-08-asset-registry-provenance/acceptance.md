# Phase 08 Acceptance
- A valid signed upload becomes canonical only after byte and checksum verification.
- Cross-tenant, expired, oversized, mismatched, and traversal transfers fail closed.

- ICM uses asset IDs and digests rather than copied binaries.
- Existing project/timeline/auth/provider behavior remains compatible.
