# Proposal: Sprint Phase 3 full-bleed landing

## Why

The existing landing direction is visually distinctive but omits the proof, offer, FAQ, metadata, and conversion truth needed to function as a credible beta entry point.

## What changes

- add repository-verified capability proof and explicit deployment caveats
- add a zero-cost gated beta offer and FAQ
- make sign-in the single working conversion target
- add metadata, analytics boundary, skip navigation, and responsive content states

## Impact

Public presentation changes only. Authentication, project, provider, storage, timeline, and billing contracts remain unchanged.
